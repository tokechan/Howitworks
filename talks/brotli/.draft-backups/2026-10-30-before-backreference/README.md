# Brotliって何？

5分LTの編集用叩き台。**本編7枚＋参考1枚**です。既存のSlidev・Geistテーマを使い、スライドは短い言葉、話す順序は発表者ノートのキーワードに分けています。

## 開く・手直しする

プロジェクトルートで実行します（Node.js 22.12以上、依存導入済み）。

```sh
npm --prefix talks/brotli run dev
```

- [通常スライド](http://localhost:3030/1)
- [発表者画面](http://localhost:3030/presenter/1)
- [スライドとノートの一覧](http://localhost:3030/overview/)

初回の依存復元だけ `npm --prefix talks/brotli ci`。終了は起動したターミナルで `Ctrl+C`。

| 直したいもの | ファイル |
| --- | --- |
| 見出し・本文・順番 | [slides.md](slides.md) |
| 話すキーワード・時間・出典 | `slides.md`の各ページ末尾の `<!-- ... -->` |
| 圧縮・転送・展開の動き | [components/CompressionFlow.vue](components/CompressionFlow.vue) |
| 荷物と作業台の動き | [components/ParcelWorkbench.vue](components/ParcelWorkbench.vue) |
| 字の大きさ・余白・色・遷移 | [styles/talk.css](styles/talk.css) |

`---`がスライドの区切りです。保存すると開発画面に反映されます。4枚目の`clicks: 3`、6枚目の`clicks: 4`は各アニメーションの進む回数です。変更するときは対応コンポーネントも合わせてください。枚数・順序・段階数を変えた後は、開いている通常画面と発表者画面を両方再読み込みしてください。

`→` / `Space`で次の段階・ページ、`←`で前へ。`F`で全画面、`O`で一覧。ノートは発表者画面かoverviewで読み、投影するのは通常スライドだけにします。ノートの冒頭に時間と話す順序、その下に根拠と補足を置いています。朗読用の台本ではありません。

## 圧縮アニメーション

4枚目で `→` を押すたびに「圧縮 → 転送 → 展開」。同じhelloをまとめ、参照と一緒に送り、元の並びに戻します。**後方参照の説明モデルで、実際のBrotli命令・ビット列・圧縮率ではありません。** 辞書・ハフマン符号などの補足はノートにあります。

- 「再生」：最初から約6秒で一巡。「一時停止」でその場に止める。
- 「戻る」「次へ」：1段階ずつ。「最初から」：圧縮前に戻る。
- 段階はSlidevのクリック位置と共通。通常画面と発表者画面で同期します。
- ページから離れると再生を止めます。再表示・更新時はURLのクリック位置を復元し、勝手に再生しません。
- 「動きを省略」で移動・変形を省略できます。OSの`prefers-reduced-motion`にも対応。状態と説明は同じです。

VueとCSS transitionのみを使い、新しい依存パッケージは追加していません。通常のスライド遷移は180msのフェードです。英数字はInter、日本語はNoto Sans JPをローカルから読み込みます。白地・黒い大きな文字、青・マゼンタ・ミントの既存配色を維持しています。

## 荷物と作業台のアニメーション

[6枚目](http://127.0.0.1:3030/6)で、初期状態の「おかしな荷物」から `→` を4回押すと「続き待ちと誤判断 → 入力を追加 → はみ出す → 正しくは異常なので止める」。トークに合わせた手動操作を基本にし、「再生」なら約8秒で一巡します。戻る・一時停止・最初から・動きを省略も使えます。一時停止は次の段階への自動進行を止め、現在の短い動きは着地まで進みます。

荷物は1個ずつ到着し、はみ出した後に境界、隣の領域、説明文の順で注目を移します。常時ループはありません。前に戻ると完成状態をすぐに表示し、途中で次へ進めば古い演出を取り消します。

最後は「正しい処理なら」と表示した別場面です。荷物を入力の作業台へ入れる前に止める対比で、破損したメモリを修復する動きではありません。荷物は圧縮入力、作業台は内部の入力バッファのたとえ。**展開後の出力が巨大化する図ではありません。** 箱の数・寸法・配置は実データや実メモリと対応させていません。細部、話すキーワード、公式出典は6枚目のノートにあります。

今回の編集前は[退避先](.draft-backups/2026-10-30-before-workbench/)に保存。4枚目の正常な圧縮アニメーションと共通の配色・書体・余白は維持しています。
