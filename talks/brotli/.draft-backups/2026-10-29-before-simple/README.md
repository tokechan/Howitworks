## 起動する

Node.js 22.12以上が必要です。プロジェクトルートから実行します。

```sh
cd talks/brotli
npm ci
npm run dev
```

`npm ci`はlockfileに固定した依存パッケージをこのフォルダへ導入します。導入済みなら、次回は`npm run dev`だけで起動できます。`dev`はデモ用ファイルをコピーしてからSlidevを起動します。

- [通常スライド](http://localhost:3030/)
- [発表者画面](http://localhost:3030/presenter/)
- [スライドとノートの一覧](http://localhost:3030/overview/)

`→` / `Space`で次、`←`で前へ進みます。`F`で全画面。終了は起動したターミナルで`Ctrl+C`です。

## 発表者ノートを読む

通常スライドと発表者画面を別のウィンドウに開き、通常スライドだけを投影・画面共有します。発表者画面の下部にあるレイアウト切り替えで、ノートを左に置く「2」にすると読みやすくなります。境界線をドラッグしてノート側を広げられます。

通し練習は保留中です。本編のノートは[通し台本](rehearsal.md)と同じ話し言葉・操作合図を収録しています。**本番で読むのは引用枠の中だけ**です。【操作】【間】【切り替え】は読み上げません。デモは時刻ごとに操作と台詞を並べています。後半の補足と出典は質疑・確認用です。`slides.md`の各ページ末尾のHTMLコメントを編集すると、ノートを修正できます。公式説明：[発表者画面](https://sli.dev/guide/ui#presenter-mode)、[ノートの書き方](https://sli.dev/guide/syntax#notes)。

## デモを見せる

7ページのボタンから、既存のBrotli Visualizerがスライド内に開きます。デモ・フォント・静止画はローカルで読み込みます。別途4177番ポートのサーバーを起動する必要はありません。

**デモの開閉・操作は、投影している通常スライド側で行ってください。** 発表者画面から同期するのはSlidevのページ移動で、シミュレーター内部の操作は別ウィンドウへ同期しません。

本番は「03 修正前と修正後」→ステップ3「判断が分かれる」→4→5→6に絞ります。「スライドへ戻る」で7ページに戻り、`→`で続けます。動作に問題があれば「静止画で見る」で同じ分岐を説明できます。

デモの途中の移動・バッファ表示は説明モデルです。実測は2026-10-27の正常なHTTP/1.1応答とNode.js 1個のリンク方式。CVEの発火・メモリ破壊・パッチの有効性は実行検証していません。

デモの正本は[simulators/brotli](../../simulators/brotli/README.md)です。起動・ビルド時に`scripts/prepare-assets.mjs`が必要な4ファイル、静止画1枚、実測ログ1個だけを`public/`へコピーします。生成されたコピーを直接編集せず、正本を更新して再起動してください。

## テーマと配色

[Vercel / slidev-theme-geist](https://github.com/nico-bachner/slidev-theme-geist) **0.8.1**を実際のSlidevテーマとして読み込んでいます。白背景・黒い太字・大きな余白を維持し、日本語LT向けに文字サイズと配置を調整しています。

スクリーンショットの3色に合わせ、同テーマのCSS変数を使います。

| 色 | 値 | 主な使い方 |
| --- | --- | --- |
| マゼンタ | `#F81CE5` | 問い、取り違え、エラー終了 |
| 青 | `#0070F3` | fetch、実測値、入力待ち |
| ミント | `#50E3C2` | デコーダー、修正の要点の下線 |

ミントは白地で細い文字にすると読みにくいため、主に黒文字の下線として使います。色だけに意味を任せず、状態を言葉でも表示します。テーマの[配色定義](https://github.com/nico-bachner/slidev-theme-geist/blob/main/styles/theme.css)が出典です。

英数字はテーマと同じInter、日本語はNoto Sans JPを使用。Fontsourceの可変フォントを同梱し、Google Fontsへの実行時通信は無効にしています。Slidev **53.0.0**と依存バージョンは`package-lock.json`に固定しました。テーマとフォントのライセンス文も`public/licenses/`・ビルド後の`dist/licenses/`に同梱します。

## ビルドして確認する

```sh
npm run build
npm run preview
```

`build`は静的配信用ファイルを`dist/`に生成します。`preview`は生成物を[127.0.0.1:3031](http://127.0.0.1:3031/)で確認するためのローカルサーバーです。`dist/index.html`を直接ダブルクリックせず、サーバー経由で開いてください。現状はURLのルートに置く構成で、GitHub Pagesへの公開設定はまだ行っていません。

Vercelテーマが古いShiki設定を使うため、ビルド時に`loadTheme`の非推奨警告が出ます。Slidev 53の互換処理でビルド・表示はできており、テーマのパッケージ自体は書き換えていません。

Floating Vue 5.4.0とTwoslashの組み合わせでは初期化時に`Failed to patch FloatingVue`が発生したため、この資料では`package.json`の`overrides`でFloating Vueを5.2.2に固定しています。依存パッケージ更新時には、この固定の要否と発表者画面・メニューの動作を再確認します。

確認内容は[verification.md](verification.md)に記録します。
