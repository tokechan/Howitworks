## 未実施・運用上の区別

- GitHub Pagesの設定、デプロイ、公開先での確認は未実施。
- 起動コマンドはビルド後プレビュー。編集の自動反映はなく、再ビルドとブラウザー再読み込みが必要。
- Pagefindはスライド内部の台本を自動収集しない。検索対象はLTのHTML紹介文。
- ビルド時にMermaidの大きなチャンクに関する通知と、既存GeistテーマのShiki APIに関する非推奨警告が出る。ビルドは成功し、図は記事中の該当箇所が近づいたときだけ読み込む。
- 通常プレビュー用4321番サーバーを引き渡し用に残し、一時的なサブディレクトリ検証用4322番サーバーは停止。
